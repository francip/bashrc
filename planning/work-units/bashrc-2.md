# Shell-only tmux session listing

Owning issue: <https://github.com/francip/bashrc/issues/2>.
Supersedes the Node routing from bashrc issue 1 for the local shell command.

The tl function invokes the Bash helper shipped with this repository. No terminal
checkout, Node or Python runtime is required. Output remains one line per session,
with session name, actual server name and detached or attached client count.

Discover standard named sockets, the current TMUX socket and additional owned tmux
listeners through Linux/WSL process-descriptor metadata or macOS lsof. Try available
system/Homebrew clients without starting servers. Keep custom paths unambiguous,
bound probes and inventory, tolerate stale sockets, and never remove or recover them.

The terminal web broker imports its Node discovery module directly. Preserve that
module and tools/tl.mjs; the local shell helper does not change web admission policy.
Web broker Homebrew alignment remains terminal issue 31.

Validate Bash and Zsh syntax, isolated routing and native session cases, and installed
behavior on Smarty, Snappy, Scrappy and Moodymoose. Preserve all existing sessions.
